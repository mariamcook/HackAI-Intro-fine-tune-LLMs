# HackAI-Intro-fine-tune-LLMs
HackAI-Intro-fine-tune-LLMs

Collection of materials to introduce Python programmers to fine-tuning and instruction tuning.

We fine-tune the BERT LLM on debate text labelled as from UK Labour and Conservative Party politicians. For completeness the notebook used to scrape parliamentary debates is also included in this repo.

There is also an example of instruction tuning, using the InstructABSA approach and templates.

We will be working on Google Colab, if you are using a different IDE please see the requirements.txt and make the necessary adapatations to model saving.
